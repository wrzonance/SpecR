    NUMBERING PROFILES

    how a section's outline is numbered — Parts, Articles, Paragraphs

    Every CSI section is built from three Parts — PART 1 GENERAL, PART 2 PRODUCTS, PART 3 EXECUTION — and inside each Part an outline of Articles, Paragraphs, and Subparagraphs. A numbering profile records the exact scheme a firm or client writes to: how many Parts, where the Articles begin, and the label style — commercial 1.01 / A. / 1. versus all-numeric 1.1 / 1.1.1. Assign one to a library and every spec parsed into it inherits that scheme instead of having it guessed; specs with none fall back to the standard CSI scheme below.

    LIBRARY PROFILES

    Parts — the most top-level Parts a section may have (CSI standard is 3). Article level — which outline depth in the Word document the Articles start at: 1 for clean ARCAT-style files, deeper when the authoring tool reserves the first level or two for its own use.
